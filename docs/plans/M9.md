## Scope summary

M9 implements boundary, facet and edge submeshes with `EntityMap` (`boundary()` replaces M3's `NotYetImplemented`), plus cell submeshes by the maintainer's decision (question 4); distributed manifold orientation (`orient`) by parity label propagation; the manifold tests of normals, pseudo-inverse and facet normals, whose kernels exist since M3 (ADR-0012); and a Newton pull-back generic over the vector size, with a device evaluator of coordinate-element bases.

## Findings from planning

Read against main at dcd6f31. Crates live at the repository root (`gridcl/`, `gridcl-geometry/`, …).

1. **Stubs.** `Mesh::boundary` returns `NotYetImplemented("boundary: M9")` (`gridcl/src/mesh.rs:650-678`, doctest :669-672; test `gridcl/tests/builder.rs:323`). `EntityMap` is `struct EntityMap { _private: () }` (`gridcl/src/entity_map.rs`). `facet_submesh`, `orient`, `OrientationRule`, any pull-back code and `GridError::{NonManifold, InteriorFacet, NeedsReferencePoint, NonOrientable}` do not exist (`gridcl-device/src/error.rs:61-152`, `#[non_exhaustive]`).
2. **Mesh assembly.** `Mesh::from_parts` (`mesh.rs:146`, crate-private), then `set_tags` (:266). `Topology::new(client, cell_blocks, vertex_index_map, vertex_origin_ids: &[i64])` (`gridcl-topology/src/topology.rs:93`) takes **host** origin ids; `set_vertex_sharers(VertexSharers)` (:259) is infallible (M6 follow-up) and there is no accessor for the stored sharers. `Geometry::new(blocks, nodes, node_index_map, origin)` (`gridcl-geometry/src/geometry.rs:63`) is device-based. Upload writes all `CellBlock::flags` as 0 (`gridcl/src/pipeline/upload.rs:27,93`); nothing writes them later.
3. **Facets in parallel.** No API gives a global facet→cell count. With `GhostMode::None` a process-boundary facet has one local cell on each of two ranks; with ghost modes the local rows over-count. Rule for every mode: count owned cells per local facet, `reverse(Add)` then `forward` over the facet block's `IndexMap`; boundary iff 1, non-manifold iff > 2. Downward cell→facet connectivity exists after `create_entities(tdim − 1)`; upward rows (`gridcl-topology/src/connectivity.rs:51`) list local cells.
4. **IndexMap subsets.** No API builds an `IndexMap` from a subset; the route is the host lists of `IndexMap::with_ghosts` (collective). A clone serves only a child that keeps every parent entity, so ADR-0026's "cloned `IndexMap`s" cannot hold for boundary or edge submeshes. A parent vertex owner may hold no child cell at that vertex, so child owners must be re-chosen.
5. **Primitives.** No compaction primitive; the pattern is flag kernel, `exclusive_scan`, count read, write kernel (`gridcl-topology/src/ownership.rs:236-317`; `TagRegistry::group`). `Scatterer::reverse` supports f32, f64, i32, u32 with `Add | Min | Max | Insert`; `ReduceOp` has only `Sum | Min | Max`.
6. **Factor kernels.** One `factor_kernel` with a comptime `Factor` (`gridcl-geometry/src/layout.rs:233`); normals read flag bit 0 per lane with `select_many` (:380-394), so CubeCL 0.11 has a lane select. Existing manifold coverage: `gridcl-geometry/tests/factors.rs::k_times_j_is_the_identity_for_all_six_pairs`, `gridcl/tests/factor_invariance.rs`. No test sets bit 0 or checks outward direction. `facet_normals` is codim 0 only.
7. **No device basis evaluation.** Bases are tabulated on the host at fixed point sets (`PointSet::tabulate`); `gridcl-refcell/src/polynomials.rs` (`orthonormal_at`, `tabulate`) is `pub(crate)` and `LagrangeElement`'s coefficients (`tabulation.rs:39`) are private. The pull-back needs X(ξ) and J(ξ) at changing ξ (rule 15). Pyramid bases are rational with a pole at ζ = 1.
8. **Pull-back scaffolding.** `KernelKind::PullBack` exists (`gridcl-device/src/policy.rs:36`) at vector size 1 in every class (`vector-policy.toml:23,68,113,158`).
9. **Reference tables.** gridcl-refcell exports `vertices`, `sub_entities`, `lagrange_points`, `lagrange_entity_nodes`, `facet_points_to_cell`, `canonical_order`; a child's closure node map follows by matching the child's `lagrange_points` mapped into the parent cell.
10. **Test meshes.** `ball`, `sphere`, `mixed_surface`, the boxes, `triangle_strip`, `HostMesh::{perturbed, mapped, first_cells, chunk}`; `gridcl_testing::parallel::{build, Case, GHOST_MODES, gather_to_root}`; `ThreadComm::run`. No Möbius strip, closed curve, non-manifold, open curved surface or flipped-cell generator.
11. **Tests and CI.** gridcl's integration tests are modules of one target, `--test integration` (`gridcl/tests/main.rs`); new modules fall into CI shard 6 of `scripts/ci-gridcl-shard.sh`. `ci.yml:148` runs `scripts/mpi-test.sh 1 2 3 4`, which runs every `[[test]]` target, so new MPI targets need no workflow edit. Compile tests: `gridcl/tests/ui/{pass/boundary_*.rs, fail/curve_boundary.rs}`.
12. **Copy list.** CLAUDE.md (ADR-0028) covers none of M9's new reads (rule 18).
13. **Carried items.** `DeviceGrid` sealing (M3 m12) is not triggered: submeshes are `Mesh`. Waiting for "the next ADR": M7 review minors 4–6, M8's `ndarray` crate-table entry, M3s B11 (gridcl-bench dependencies).

Rules (each an ADR-0039 item):

1. **`EntityMap`.** As above, on the device for every local child cell, vertex and node. For facet children the parent cell and local facet are kept crate-private (geometry and flags).
2. **`OrientationRule`.** Points are `[f64; 3]` in absolute coordinates; the first `gdim` entries are used, since `orient` (Listing B4) has no GD-dependent argument.
3. **`edge_submesh`** (maintainer, 2026-11-05: volume meshes only). Tagged edges of `Mesh<F, D3, D3, C>`, interior or boundary.
4. **`cell_submesh`** (maintainer, 2026-11-05: in M9, beyond the roadmap scope). Tagged cells, same (TD, GD); the roadmap's M9 scope gains it.
5. **Prerequisites** (maintainer, 2026-11-05: errors). Submesh methods take `&self` and create no topology (Listing B7): `boundary` and `facet_submesh` need `create_entities(tdim − 1)` (`EntitiesNotCreated`); `edge_submesh` needs `create_entities(1)` and `create_connectivity(1, 3)` (`ConnectivityNotCreated`). `orient` takes `&mut self` and creates the (tdim − 1) entities and (tdim − 1, tdim) connectivity it needs.
6. **Ownership and numbering of a child.**
   - Cells inherit the parent entity's owner and ghost status, including ghost child cells where the parent holds the entity as a ghost; no new ghost layer.
   - Child `VertexSharers`: the parent's rows restricted to ranks holding the vertex in a child cell (with owned-child-cell flags), by one exchange over the parent's sharing neighbourhood for shared vertices only. Vertex owners follow the design's rule: `owner_hash(&[origin id]) mod n` among the owned-child-cell sharers.
   - Nodes: a corner node takes its vertex's owner. Any other node takes the same rule with the key `[parent global node index]` (node origin ids are not stored on a mesh, M8 finding 7), its candidates collected by the parent node owner over the node `IndexMap`'s neighbourhoods.
   - Local order: owned in parent local order, ghosts by (owner rank, child global index). Global numbers by exclusive scan. A ghost's child global index travels from the child owner to the parent owner (reverse) and then to every holder (forward). `IndexMap::with_ghosts` on more than one rank, `IndexMap::new` on one.
   - ADR-0026's "cloned `IndexMap`s" is amended accordingly: a clone only where a child keeps every parent entity.
7. **Child cell origin ids** (partition-independent):
   - facet child: 8 · (parent cell origin id) + local facet index;
   - edge child: the minimum over the cells containing the edge of v = 12 · (cell origin id) + local edge index (checked i64), reduced across ranks by `Min` on the interleaved hi word, `forward`, then `Min` on the lo word with non-matching hi words set to `u32::MAX`, `forward`;
   - cell child: the parent's.
   - An overflow gives `TooLarge` (agreed). Vertex origin ids are the parent's ("Reference cells and conventions").
8. **Child vertex order, geometry and flags.**
   - Facet children take the parent cell's local facet vertex order and the facet's geometry nodes in the child's reference order (closure node map, finding 9). The child geometry is the restriction of the parent's, with the same degree and family.
   - Edge children take the canonical orientation (A.6). Interior nodes come from the first local cell in the edge's (1, 3) row, reversed where that cell's local edge runs the other way.
   - Codimension-1 children (of volume and planar meshes) set flag bit 0 where the child's geometric normal at the facet midpoint has a negative dot product with the parent's outward facet normal there ("each facet cell is oriented so that its normal agrees with the outward facet normal of its single parent cell"). The alternative, a per-(cell type, local facet) table times the sign of the parent's det J, is not proposed (it needs a det J evaluation too).
   - "Oriented outward" has no meaning for codimension-2 children (the boundary of a surface in 3D, edge submeshes): their flags are 0. Listing B4's `boundary` doc says so.
   - A child block whose parent cells differ in degree or node family gives `UnsupportedDegree` or `UnsupportedNodeFamily` for the facet type (agreed).
9. **Child origin.** The child keeps the parent's origin, so its coordinates are bitwise the parent's in every precision. This amends "Coordinate element and storage" for submeshes.
10. **Child blocks and tags** (maintainer, 2026-11-05: cell-level tags).
    - One child cell block per parent entity block (or cell block) with a non-zero global child count, in the parent's order and the same on every rank. A rank may hold an empty block. A child with no cells is a valid empty mesh: `boundary()` of a closed surface, after `create_entities(1)` on it.
    - The child's `TagRegistry` holds the parent's physical and elementary tags of the dimension the child cells come from, restricted and renumbered as child cell tags, with those name-table rows. Lower-dimensional tags are not carried.
11. **`boundary` and `facet_submesh`.** Boundary facets have exactly one owned cell globally (finding 3). Any facet with more than two gives `NonManifold`, from `boundary` and `facet_submesh` alike. A tagged facet with two gives `InteriorFacet`. Tags of another dimension give `DimensionMismatch`. All errors are agreed.
12. **`orient`.**
    - Existing flags are ignored and overwritten; ghost cells get their owner's flags.
    - Manifold check: any facet with more than two owned cells globally gives `NonManifold`.
    - Parity per interior facet as in "Manifold orientation", step 2: the reference boundary cycle with the edge permutation bit, or start/end vertex for curves.
    - **Neighbour table**, built once from the (tdim − 1, tdim) rows: per cell and local facet, one packed record (neighbour flat cell or none, parity), strided per cell block. **State:** one record per flat cell (label hi, label lo, parity, pointer), double-buffered. A round kernel per block binds state in, state out, neighbour table and a change word: at most four buffers.
    - Propagation is min-label adoption with parity plus pointer jumping (shortcutting). It is Jacobi-style (no atomics) and deterministic. Rounds are bounded by component diameter in the worst case, and logarithmic for ids that increase along a strip.
    - Between rounds, the state of the cells on both sides of every process-boundary facet is exchanged over the facet `IndexMap`: `reverse(Max)` of the single non-owner contribution (encoded + 1, others 0), then `forward` of both sides. This works in every `GhostMode`. Ghost cells take their owner's state by `forward`. A round ends with `comm.max(changed)`.
    - `NonOrientable`: after convergence, any interior facet, process-boundary facets included (the same exchange), whose cells violate s_a · s_b = (−1)^parity.
    - Direction:
      - Per component (label), owned cells contribute to (1/D_GEO) ∮ x·n, or ∫ (x − p)·n, with Gauss degree 3p (the largest over blocks).
      - The contributions are summed per label on the device, finished in f64 on the host, and combined at rank `owner_hash(&[label]) mod P` in rank order.
      - Open components (any boundary facet) give `NeedsReferencePoint` under `Outward`. A sum of exactly 0 flips nothing (documented).
    - Errors are agreed. Kernels plan as `KernelKind::Scalar`.
13. **Pull-back iteration.**
    - The input is a `BlockFields<F, VecShape<GD>>` of absolute physical points per cell and point, as `physical_points` returns. "Points tiled like cells" therefore holds: lanes are consecutive cells of a tile reading the E-vector, as in the factor kernels. Plans use `KernelKind::PullBack` with `max_vector = tile`.
    - Start at the reference cell's vertex centroid and set Δ = K(ξ)(x − X(ξ)), with K the pseudo-inverse (Gauss–Newton in codimension > 0, Newton in codimension 0).
    - A lane freezes once |Δ|∞ ≤ tolerance. Frozen lanes keep ξ through a lane select, not a multiply, so NaN or Inf in another lane's arithmetic never reaches them.
    - The loop always runs `max_iterations`, with no early exit: CLAUDE.md's "no branches on lane values" holds as written, and results are identical at every vector size.
    - Non-convergence shows in `last_step`, not as an error.
    - Default tolerance (`None`): 10^−13 in f64 and 10^−5 in f32. Absolute input coordinates lose about |origin| · ε_F, as `physical_points` does.
14. **Vector-size invariance of the pull-back.** Bitwise on the CPU runtime (ADR-0013). The acceptance bullet's 10^−12 is the GPU tolerance in f64 (10^−5 in f32).
15. **Device basis evaluation** (maintainer, 2026-11-05: orthonormal recurrences).
    - The device evaluates the orthonormal basis of "Tabulation" (Legendre, Dubiner, orthonormal rationomials) and its first derivatives by the host's recurrences, in `#[cube]` helpers specialised at comptime by cell type and degree.
    - It combines them with `LagrangeElement::coefficients` (f64, narrowed to F), uploaded once per geometry block on first use and cached like the E-vector.
    - Pyramid ζ is clamped to at most 1 − 2^−10 before evaluation, an arithmetic `min` and documented.
    - The pull-back kernel binds the input points, the E-vector, the coefficients, ξ and `last_step`: five buffers.
16. **`set_vertex_sharers` becomes fallible** (M6 follow-up): `-> Result<()>`, with length, ordering and own-rank checks (`LengthMismatch`, `IndexOutOfRange`). This changes the signature in "Ownership of vertices and entities".
17. **Hidden cross-crate hooks (ADR-0038)**, each documented "not part of the stable API" with a named test:
    - `Topology::from_device_ids(client, cell_blocks, vertex_index_map, vertex_origin_ids: DeviceBuffer<u32>)`, with interleaved ids, computing permutation info like `new`;
    - `Topology::set_cell_flags(b, DeviceBuffer<u32>) -> Result<()>`;
    - `Topology::vertex_sharers() -> Option<&VertexSharers>`;
    - `gridcl_topology::facet_cell_counts(comm, topology) -> Result<FacetCells>`;
    - `gridcl_geometry::orientation_flags(g, rule) -> Result<Vec<DeviceBuffer<u32>>>`.
18. **Copy list** (CLAUDE.md, amended as ADR-0026/0028 did):
    - submesh creation: the per-block count reads of compaction, the agreed `TooLarge`/`NonManifold`/`InteriorFacet` flags, the child ghost lists (global indices and owners) for `IndexMap::with_ghosts`, the child sharer rows of shared vertices and the node-owner candidates of shared nodes, the upload of the closure node maps, and the child's vertex shared flags (`set_vertex_sharers` at submesh creation);
    - `orient`: the per-round change flag, the agreed error flags, the per-component (label, sum, open) records and the flip decisions;
    - pull-back: the upload of the expansion coefficients on first use.
19. **Manifold tests (ADR-0012 item 10).** Normals: unit length, orthogonal to J's columns, flipped by bit 0, outward after `boundary()` and `orient`. Pseudo-inverse: K J = I, J K J = J and J K n = 0 on curved boundary submeshes. Facet normals: the parent's `facet_normals` at boundary facets equal the boundary submesh's `normals` at the same points.
20. **Carried corrections:** M7 review minors 4–6 (`scotch-sys-bindgen` in the crate table; ADR-0029 item 5 says parmetis-sys links `parmetis` and `metis`, it links `parmetis`; the FFI rule covers a -sys crate's own tests and examples), M8's `ndarray` crate-table entry, and M3s B11 (gridcl-bench's gridcl-refcell dependency and proptest dev-dependency).
