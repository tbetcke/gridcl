## Scope summary

Hosted CI's MPICH jobs start every rank as a singleton, so the MPICH half of "under both MPICH and Open MPI"
has never run on more than one rank (ADR-0068). E2 adds the rank-count guard of the roadmap entry
(`TETRALOMA_EXPECT_RANKS`, set by `scripts/mpi-test.sh` and `scripts/run-examples.sh`, checked by
`tetraloma_mpi_tests::run` and the MPI examples), moves `mpi-mpich` and `mpi-mpich-hdf5` to `ubuntu-26.04`,
and fixes whatever the first real multi-rank MPICH runs expose. No public API changes; the library crates
are not touched unless T3 finds a bug.
