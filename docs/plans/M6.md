## Scope summary

M6 delivers four things:

- `Mpi` and its `mpi::ffi` wrappers;
- `IndexMap` with ghosts;
- the host-staged `Scatterer`, with a deterministic reverse and with pack and unpack kernels (`KernelKind::Pack`) generic over the vector size;
- pipeline stages 1–10 from host arrays with the block partitioner, ghost modes, the ownership rules, global numbering and locality ordering.

The acceptance tests run on 1–4 ranks under MPICH and Open MPI.

## Findings from planning

1. **No distributed builder.** `MeshBuilder` (`gridcl/src/builder.rs:118`) builds `Serial` meshes only. `build_with_comm` (l.185) is crate-private and serial. `cell_block` takes local u32 node indices (l.150–157), so on more than one rank a cell cannot reference a node in another rank's chunk. The design gives no public API for distributed input or for tag input (ADR-0026 rows 1–3).
2. **Serial-only collectives in mesh creation:**
   - the bounding-box origin is local (`builder.rs:259-270`);
   - every map comes from `IndexMap::new` (`builder.rs:293,312,318`, `entity.rs:359,432`, `topology.rs:20,246`, `geometry.rs:171`);
   - `try_clone` asserts ghost-free maps (`topology.rs:15`, `geometry.rs:157`; M3 follow-up).
3. **No stage-6 hook in entity creation.** Entity creation has no ownership step. `renumber` (`gridcl-topology/src/renumber.rs:125`) treats every entity as owned. Ownership needs the per-vertex sharer sets of pipeline stage 8 (row 8).
4. **`Scatterer` has nothing to exchange through.** Its methods take no communicator (Listing S2c, B13). A `Neighbourhood` without a communicator cannot exchange under `ThreadComm`, and `create_entities` only borrows `&dyn CommDyn` (row 4).
5. **Missing pieces for the exchange:**
   - gridcl-parallel has no cubecl dependency;
   - `DeviceBuffer` cannot upload into an existing buffer;
   - pack and unpack do not exist.

   `KernelKind::Pack` and its policy entries (size 1) exist (ADR-0015), and gridcl-bench has the record slot for M10 (rows 12, 13).
6. **Tags come only from the serial Gmsh reader.** Group sizes are local and include ghosts.
7. **MPI flavours and test hooks:**
   - MPICH is not installed on the M3 Max, so CI's `mpi-mpich` job covers it.
   - Locust has Open MPI 5.0.10, and its two ranks share one GPU.
   - `scripts/mpi-test.sh` runs every target and has no filter.
   - The `testing::with_*` hooks are thread-local.

**Input contract of `build_on`** (rows 1–3, 15)

- **Nodes.** Each rank passes a chunk of nodes, and each node appears on exactly one rank. A duplicate gives `DuplicateOriginId`.
- **Cells.** Each rank passes a chunk of cells.
  - `cell_block_by_ids` references nodes by origin id.
  - `cell_block` references nodes by u32 indices into the rank's own chunk, which are translated to ids on that rank. This path is valid only when the rank's cells use only its own nodes; it is always valid on one rank.
- **Default ids.** Default origin ids are global construction indices: an exscan of the counts plus the local index, the same as today's serial default.
- **Nodes no cell uses** are dropped. `NodeRoleMismatch` is checked globally, in the stage-6 directory.
- **Cell blocks** are the union over ranks, in order of first declaration by rank. A rank without cells of a block gets it empty. One cell type in two degrees gives `DuplicateCellBlock`.
- **Errors are agreed.** Every rank returns `Err`. A rank without a local error returns `RemoteFailure { rank }`, where `rank` is the lowest failing rank.
