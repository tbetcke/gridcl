## Scope summary

M8 makes gridcl's file I/O parallel. Binary Gmsh files are read in byte-range chunks per rank, and ASCII files on rank 0 and scattered; both feed the M6 pipeline as stage-1 file chunks. `GmshWriter` gathers to rank 0 or writes one partitioned file per rank with `$PartitionedEntities`. `VtkWriter` writes VTU (gathered) and PVTU pieces on every rank with a `vtkGhostType` cell array. A VTKHDF writer (feature `hdf5`, hdf5-metno with `mpio`) writes one file with per-rank offsets, the same cell types and the same ghost array.

## Findings from planning

1. **Parser is whole-file.** `gridcl_io::gmsh::read_file` (`gridcl-io/src/gmsh/parse.rs:572`) uses `std::fs::read`; `parse` (:524) is one forward pass. Binary records have fixed size (`size_t` 4 or 8, either byte order; `parse/binary.rs`), so block headers can be scanned by seeking.
2. **Conversion.** `to_gmsh_mesh(file, comm, gdim)` (`gmsh/convert.rs:421`) infers D_GEO with `comm.max` but checks duplicates and node presence (`Parse`) on the whole file. Partitioned files: elementary tags from parent entities, interface entities dropped (`entity_info`, :169); `ghost_entities` unused. `from_gmsh_mesh` (:721) computes the largest vertex id and the tag shift per call and never emits `$PartitionedEntities`; `MshFile::write_to` (`gmsh/write.rs:226`) writes it if present.
3. **`gmsh::read`** (`gridcl/src/gmsh.rs:221`) refuses `size() > 1` (:227), builds with `nodes` + `cell_block` and tags cells by flat input index (:90-103). Its test `gmsh_read_unmatched_tag_element_and_io` (:637) expects the Gmsh element tag in `UnmatchedTagElement`. `GmshOptions` is `#[derive(Clone, Debug, Default)]` with only `gdim`.
4. **Builder** (`gridcl/src/builder.rs`): `cell_block_by_ids`, `physical_tags`, `tag_names`, `ghosts`, `partitioner`, `ordering`, `build_on`, hidden `dual_graph_on`, crate-private `build_with_comm`. Cell tags match by keyed rendezvous in stage 1 (`pipeline/input.rs:296ff`, `match_cell_tags`); lower tags after upload (`pipeline/tags.rs::match_lower`), whose `UnmatchedTagElement.tag` is the entry's global input position. Duplicate cell ids (`check_cell_ids`) and node ids (stage-6 directory) are already found. Rendezvous helpers (`Outbox`, `rendezvous_rank`) are crate-private in `gridcl/src/pipeline/rendezvous.rs`. **No elementary tags, no per-cell tag values, no fixed destinations** in the builder.
5. **Partitioners.** `PtScotch`/`ParMetis` return `NeedsMpiCommunicator` when `comm.raw()` is `None` (`gridcl-partition/src/ptscotch.rs:33`), e.g. on `ThreadComm`. The ptscotch workflow runs `cargo test -p gridcl --doc -- partitioner` (`ptscotch.yml:76`).
6. **Writers include ghosts without distinction.** `gmsh.rs::download` (:307), `vtk.rs::download` (:92) take `0..num_local` per block. Ghosts of block b are local indices ≥ `num_owned()`; flat cell order interleaves ghosts per block (`pipeline/number.rs:28-31`). `write_pvtu(w, pieces, like)` (`gridcl-io/src/vtk/write.rs:471`) hard-codes `GhostLevel="0"`.
7. **Node origin ids are not stored** on the mesh (dropped at upload); only vertex origin ids survive.
8. **`NotYetImplemented("… (M8)")`**: `gmsh.rs:228`, `:485`, `vtk.rs:451`, `:453`; tests `gmsh_read_needs_one_rank`, `vtk_write_needs_one_rank` (`TwoRanks`) to be replaced.
9. **HDF5.** gridcl `hdf5 = ["gridcl-io/hdf5"]`; gridcl-io `hdf5 = []` (placeholder). hdf5-metno 0.15.1 (MSRV 1.85.1; sys 0.12.5 knows HDF5 1.8.5–1.14.6 and 2.0–2.2.0) has `mpio = ["dep:mpi-sys", "hdf5-sys/mpio"]` with `mpi-sys = "0.2"` (rsmpi 0.8.2 uses mpi-sys 0.2.4) and a safe `FileAccessBuilder::mpio(comm, info)`. Local: Homebrew `hdf5-mpi` 2.2.0, parallel ON. Ubuntu 24.04: `libhdf5-{mpich,openmpi}-dev` = 1.10.10. Kathleen: no HDF5 needed (bullets 3–4 run at 1–4 ranks).
10. **Oracles.** `scripts/oracles/vtk_oracle.py`: `read` (incl. `.pvtu`), `integrate`, `evaluate`, `meshio`, `versions`; no VTKHDF, no ghost removal. `Oracle` lives in `gridcl/tests/common/python.rs`. CI's `mpi` job has no Python.
11. **Tests.** gridcl-mpi-tests targets are thin `main`s around `gridcl_mpi_tests::run` (`gridcl-mpi-tests/src/lib.rs:17`) over checks in `gridcl_testing::parallel` (`gather_to_root`, `ThreadComm::run`). `scripts/mpi-test.sh` builds debug `cargo test` (600 s timeout). Gmsh corpus: 60 small files (largest 77 KB); one partitioned file, ASCII, 2 parts, no ghost entities.
12. **Kathleen** nodes are diskless (`TMPDIR` is RAM); the 10^7-cell file (~460 MB) goes to the remote tree's `target/` on Lustre.
13. **No kernel changes are planned** (downloads and writers are host side over existing primitives): no vector-size invariance rows; Locust at the review, and after T5b if it touches kernels.

Rules (each an ADR-0035 item):

1. **Stage 1 from files.** Every rank scans headers and small sections. D_TOP elements, concatenated in file order, are chunked as [rN/P, (r+1)N/P); tag elements and nodes likewise, independently. Cell blocks are declared on every rank in `CellType` order from the global scan (empty blocks included). On one rank behaviour equals M4.
2. **Rank-0 read and scatter** for ASCII files (design) and for binary files with serendipity elements (types 16–19): the upgrade needs neighbours' face nodes and fresh tags "in order of first use", which are global.
3. **Errors keep their serial form.**
   - `UnmatchedTagElement.tag` is the Gmsh element tag: the crate-private tag input carries a per-entry error id; the agreed error picks the entry with the lowest input position.
   - A node referenced by an element but missing from `$Nodes` stays `Parse` (stage 6's `IndexOutOfRange` is mapped back by the reader).
   - Duplicate node tags and duplicate element tags (one tag space over all dimensions) give `DuplicateOriginId`: cell ids and node ids by the existing pipeline checks; tag-element ids against each other and against cell ids by a crate-private rendezvous in gridcl. D_GEO by allreduce over node chunks.
   - Every error is agreed (ADR-0026 item 15).
4. **Tags.** D_TOP physical and elementary values ride on their cells as crate-private per-cell values in stage 1 (no keyed rendezvous). Lower-dimensional tags use `match_lower` with an elementary path beside the physical one. ADR-0026's "only physical tags" becomes "only physical tags publicly; the reader also passes elementary tags". Group sizes stay local counts.
5. **Partitioned files.** With `Block` (explicit or the default fallback) and `numPartitions == comm.size()`, each D_TOP element goes to rank `partition − 1`; stages 2–3 are skipped (crate-private fixed destinations). Otherwise the partition data is ignored. Ghost entities in the file are ignored.
6. **Default partitioner** when `size() > 1`: PT-Scotch with `ptscotch` and `comm.raw()` = `Some`; else `Metis` with `metis`; else `Block`, with one `log::warn!` on rank 0. One rank: none. Warnings (Block fallback, f32 narrowing, pyramids) are logged once, on rank 0.
7. **`GmshWriter` on P > 1 ranks.** Writes are collective and end with an agreed status.
   - Default: owned cells, their nodes and owned tag entities gathered to rank 0, one file; cells by (rank, local owned order), nodes in global node order.
   - Node tags: vertex origin ids; other nodes get (allreduced max vertex id) + 1 + their position among non-vertex nodes in global node order (exscan over owned nodes, forward scatter to ghosts). Tag elements numbered after the allreduced largest cell id by exscan over owned tag entities. The shift of tags below 1 uses allreduced minima. On one rank this is M4's rule.
   - `.partitioned(true)`: rank r writes `<stem>_<r+1>.msh` with its owned cells, the nodes they use, its owned tag entities, `$Entities` with the parent entities and `$PartitionedEntities` (numPartitions = P; one partitioned entity per (elementary tag, physical set), parent = that entity, partitions = [r+1]; no ghost entities). Each file reads serially as that rank's part (M4 rule 13).
8. **`VtkWriter` on P > 1 ranks.** Collective with agreed status.
   - `vtu`: owned cells gathered to rank 0, one file, points in global node order; no ghost array.
   - `pvtu`: each rank writes its piece with all local cells and nodes plus cell data `vtkGhostType` (UInt8; 0 owned, 1 = `DUPLICATECELL`) when `size() > 1`; rank 0 writes the header with `GhostLevel` = 1 if any rank has ghost cells, else 0. One-rank output unchanged (M5).
   - `vtkhdf`: the same pieces in one VTKHDF UnstructuredGrid (per-piece `NumberOfPoints`, `NumberOfCells`, `NumberOfConnectivityIds`; piece-local `Connectivity`; `Offsets`, `Types`, `CellData`, `PointData`; the format version VTK 9.7.1's `vtkHDFWriter` writes; libver bounds low = v18 so the VTK wheel's HDF5 reads it — checked in T9). With `comm.raw()` = `Some` (features `mpi` + `hdf5`) it writes collectively through `mpio`, empty pieces taking part in every collective call; otherwise (`Serial`, `ThreadComm`) pieces are gathered and rank 0 writes. Datasets and attributes are identical either way. `base64` is ignored; `zlib(true)` gives `NotYetImplemented("compressed VTKHDF")`.
   - Point and cell data follow the same selection; `origin_ids(true)` adds `OriginId`.
9. **Features and dependencies.** gridcl-io: `hdf5 = ["dep:hdf5-metno"]`, new `mpi = ["gridcl-parallel/mpi", "hdf5-metno?/mpio"]` forwarded by gridcl's `mpi`. `hdf5` builds with HDF5 1.10.10–2.2.0; `hdf5` + `mpi` needs a parallel HDF5 (`HDF5_DIR`). `hdf5-metno = "=0.15.1"` in `[workspace.dependencies]`; a safe wrapper, so no FFI-rule change. Test-only: gridcl-testing gains `serde_json` (oracle) and `[[bin]] gen-gmsh-box`; gridcl-mpi-tests gains `nix` (unix, feature `resource`) and features `hdf5`; gridcl-io gains dev-dependency gridcl-testing.
10. **Memory acceptance.** "Final mesh size" = `Mesh::footprint_bytes()`: byte lengths of every device buffer of the mesh (topology, entities, connectivity, geometry, tags) plus its index maps' host vectors, when `read` returns. Peak = `getrusage(RUSAGE_SELF).ru_maxrss` via `nix` (KiB on Linux, bytes on macOS). File: `cube_box(Tetrahedron, 119, 1)` (10 110 954 cells), one volume and six side physical groups, binary, written by `gen-gmsh-box` into `target/m8/` in a separate process before the measured `mpirun`. Read with `Block`, `GhostMode::None`, release build; on Linux the measured `mpirun` sets `GLIBC_TUNABLES=glibc.malloc.mmap_threshold=1048576:glibc.malloc.trim_threshold=1048576` and forwards it with `-x GLIBC_TUNABLES` (ADR-0036). (METIS on rank 0 gathers the whole graph and would break the bound by design; PT-Scotch is logged, not asserted.)
11. **Bullet 1, "global mesh identical"**: gathered to rank 0 by cell origin id — cell type and degree, vertex origin ids in cell order, all node coordinates per cell in internal order (bitwise), physical and elementary tags keyed by sorted vertex-origin-id tuples, the name table — equal to the one-rank read. Full corpus (ASCII, binary) at 1, 2, 3, 4 and 8 ranks/threads; a subset (one file per cell type, partitioned, serendipity, the generated multi-block box) at 5–7. `GhostMode::{None, SharedFacet}`; on MPI every enabled partitioner, on threads Block (and Metis with `metis`).
12. **Bullet 3, "VTKHDF equals PVTU"**: `vtkHDFReader` output and `vtkXMLPUnstructuredGridReader` output (ghost level 1 requested) are equal array by array, bitwise: points, connectivity, offsets, types, every cell and point array including `vtkGhostType` and `OriginId`, and the per-piece counts.
